# 03 · 优秀教育系统能力对标基线（外部产品能力矩阵）

- 调研目的：为"中国 K12 教培机构运营平台（三端：管理端 / 教师端 / 家长端）应补哪些能力"提供外部基线，只做产品能力对标与价值判断，不含本机构落地方案建议。
- 对标范围：A 国际 LMS / 学习平台；B K12 课堂与家校产品；C 中国教培运营 / 家校产品。
- 判断口径：价值分 **高 / 中 / 低 / 不适用**；复杂度分 **低 / 中 / 高**。"不适用"指该能力的设计场景与 K12 教培机构业务不匹配，不应照搬。
- 链接状态：除特别标注外，引用 URL 均于 2026-11-05 脚本实测返回 HTTP 200；个别第三方帮助中心对脚本反爬（403）的条目未纳入矩阵，改用可访问的官方页面。

## 0) 三类产品定位差异（为什么不能拿一类的功能清单直接套另一类）

### A 类：国际 LMS / 学习平台
- 以**课程内容承载与在线学习交付**为中心，强在课程结构、作业测评、成绩册、学习分析、证书与内容互操作规范；角色模型以"教师—学生"为主，家长角色普遍缺失或很弱。
- 设计假设：学员自主注册/选课、学习周期长、内容可跨平台复用、有正式成绩与证书出口；多为高校、成人培训、企业培训场景。
- 与 K12 教培的差距：基本不处理招生、收费、课包消课、教师课时工资、排课冲突、家长续费沟通等**机构经营**问题；课标对齐、学分、SCORM/xAPI、LTI 等是为学校/大学场景设计，搬到周末培训班属于冗余。

### B 类：K12 课堂与家校产品
- 以**课堂过程记录 + 家校连接**为中心：ClassDojo/Seesaw/Bloomz 偏行为激励、作品档案与家长沟通；PowerSchool/Edsby 偏公立校 SIS、成绩册与家长门户；Khan/Duolingo 偏练习、掌握度与游戏化。
- 设计假设：依附公立校建制（固定班级、学期、学籍、课标、统考），家长多为被动接收方；不直接承担机构经营转化职能。
- 与 K12 教培的差距：激励、档案、沟通、作业摘要等环节可直接借鉴；但其成绩册权重模型、标准对照、考务、学区报表围绕公立校学期与合规设计，教培机构不需要。

### C 类：中国教培运营 / 家校产品
- 两条产品线：**运营 SaaS**（校管家、校宝在线、爱耕云：招生 CRM、排课、考勤课消、收费退费续费、教师绩效、经营报表）与**教学/家校工具**（班级优化大师、希沃白板、翼课网、一起作业、晓黑板：课堂点评、课件、同步练习、错题、通知打卡）；小鹅通介于"线上内容店铺 + 私域运营"之间。
- 设计假设：老板/教务/教师/家长多角色并存，核心诉求是降本增效、消课续费、家长满意度；教学内容深度多依赖外部题库或自研，平台本身不做完整课标课程。
- 与本次调研对象最接近：排课—考勤—课时—薪资—反馈—家校等模块直接对标 C 类运营 SaaS；练习测评、课堂互动、成长档案参考 B/C 类教学工具；A 类仅在课程结构、作业闭环、成绩册、学习分析等少数能力上有参考价值。
