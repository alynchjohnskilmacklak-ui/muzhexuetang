# 生产部署入口

生产环境统一使用 Linux 预构建发布包。不要上传整个项目目录，也不要在服务器上执行 `npm install`、`npm run build`、`prisma db push` 或旧版源码部署脚本。

当前阿里云 Workbench 单 `.tar` 总包流程见 [阿里云预构建部署说明.md](阿里云预构建部署说明.md)。底层预构建说明见 [docs/prebuilt-deployment.md](docs/prebuilt-deployment.md)，生产安全约束见 [docs/production-safety.md](docs/production-safety.md)。

## 1. 本机构建

先启动 Docker Desktop，然后在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-linux-release.ps1 -Registry https://registry.npmmirror.com
```

脚本会在 Linux Node 22 容器中安装依赖、构建、执行 `/login` 冒烟检查，并在 `release/` 生成且默认只保留最近两个版本：

```text
edu-manage-runtime-YYYYMMDD-HHMM.tar.gz
edu-manage-runtime-YYYYMMDD-HHMM.tar.gz.sha256
```

## 2. 上传

两个同名文件必须一起上传：

```powershell
scp ".\release\edu-manage-runtime-YYYYMMDD-HHMM.tar.gz" root@<服务器IP>:/tmp/
scp ".\release\edu-manage-runtime-YYYYMMDD-HHMM.tar.gz.sha256" root@<服务器IP>:/tmp/
```

## 3. 部署

```bash
cd /opt/edu-manage
bash scripts/deploy-prebuilt-tar.sh /tmp/edu-manage-runtime-YYYYMMDD-HHMM.tar.gz
```

第一次切换到该流程时，先按完整说明单独安装最新版 `scripts/deploy-prebuilt-tar.sh`。部署脚本会校验哈希、备份数据库、执行迁移、候选端口健康检查、切换 PM2，并在失败时保留或恢复旧版本。

## 4. 验证

```bash
pm2 status edu-manage
curl -fsS http://127.0.0.1:3000/login >/dev/null && echo OK
readlink -f /opt/edu-manage/current
pm2 logs edu-manage --lines 30 --nostream
```

发布包只含运行产物、静态资源、Prisma schema/migrations、独立迁移工具和三个生产脚本。`.env`、源码、测试、文档、缓存、旧发布包以及服务器共享上传目录都不会打入包内。

# DESIGN.md — UI Design System

Before building or modifying any UI, read `DESIGN.md` at the project root. It defines the complete visual design system: colors, typography, spacing, components, and guardrails. All UI must follow the design tokens and patterns defined there.

## Design System Summary

- **Style**: Warm light education platform (牧哲学堂)
- **Canvas**: `#faf8f5` (warm cream)
- **Primary accent**: `#E8784A` (warm orange) — use for CTAs, focus rings, selected states
- **Text**: `#1a1201` (warm near-black)
- **Font**: Geist Sans (--font-geist-sans) + Geist Mono (--font-geist-mono)
- **Border radius**: 10px interactive, 14px containers
- **Component library**: Ant Design v5 with custom warm-light tokens
- **CSS framework**: Tailwind CSS v4 with @theme tokens matching DESIGN.md

## Quick Rules

1. Always use the warm light theme (#faf8f5 canvas).
2. Cards use `#ffffff` background with `1px solid rgba(0,0,0,.06)` border and 14px border-radius.
3. Primary buttons use `#E8784A` background with white text.
4. Use design tokens from globals.css or Ant Design ConfigProvider; do not hardcode colors.
5. Login page is the exception: dark-themed left panel with photo grid, warm-light right form.


## Project Safety Rules



- Before frontend changes, read docs/frontend-rules.md and DESIGN.md.

- Before production/deployment changes, read docs/production-safety.md.
