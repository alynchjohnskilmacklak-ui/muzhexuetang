# 牧哲學堂行书字形

`cursive.json` contains the four actual glyph outlines from MasaFont Regular (正風毛筆字體), based on Kouzan Gyousho by Kouzan Aoyagi and extended by Chun yu Yao / max32002.

Source: https://github.com/max32002/masafont
Source font: https://github.com/max32002/masafont/blob/master/tw/MasaFont-Regular.ttf
License: SIL Open Font License 1.1, copied from the font metadata to `MASA-OFL.txt` and served at `/licenses/masa-font/OFL.txt`.

Generated 2026-11-19: the glyph outlines are preserved as vector graphics. Separate medial reveal paths control ink appearance without adding any visible connections between characters. The complete outline is retained at the end of each character. Only the four outlines and reveal data are bundled; playback downloads no external fonts.
