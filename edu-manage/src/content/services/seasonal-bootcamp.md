# 牧哲学堂 · 初中/高中寒暑假冲刺预备课优势说明

> 牧哲学堂成立于 2016 年，专注中小学课外辅导，目前已在石家庄、邢台、唐山、邯郸、张家口等地陆续开展校区服务。寒暑假课程采用集中学习、系统复习、查漏补缺、专项训练相结合的方式，帮助学生在假期实现集中突破。

---

## 一、课程概览

### 1. 课程周期与安排

| 项目 | 说明 |
| ---- | ---- |
| 暑假班 | 26 天 |
| 寒假班 | 16 天 |
| 每日学习时长 | 约 6 小时 |
| 教学方式 | 集中学习 + 系统复习 + 查漏补缺 + 专项训练 |

### 2. 年级与科目设置

| 年级 | 开设科目 | 课程定位 |
| ---- | ---- | ---- |
| 初一 | 语文 · 数学 · 英语 · 生物 | 打牢基础、建立学习习惯 |
| 初二 | 语文 · 数学 · 英语 · 物理 | 查漏补缺、平稳过渡分水岭 |
| 初三 | 数学 · 物理 · 化学 · 英语 | 中考冲刺、专项提分 |
| 高一 | 数学 · 物理 · 化学 · 英语 | 高中预备、改变学习态度 |
| 高二 | 数学 · 物理 · 化学 · 英语 | 夯实基础、平稳度过高二最难时刻 |
| 高三 | 数学 · 物理 · 化学 · 英语 | 高考冲刺、提前进入一轮复习 |

> 注：高中阶段课程目前体现在 SVIP 权益的「学习规划沟通服务」中，围绕升学衔接、冲刺、选科和高考规划提供建议，具体课程方案可按需补充。

## 二、核心优势

### 1. 教学精准：教材 100% 紧贴中考大纲

- 所有教材和资料均围绕河北中考大纲与学生实际学习需求设计；
- 只讲中考常考、必考、易错知识点，不做无效堆砌；
- 把寒暑假有限的时间，用在真正重要的地方，不浪费学生一分钟。

### 2. 师资可靠：211/985 硕士 + 持证上岗

- 所有授课教师均为 211/985 高校硕士研究生，持教师资格证上岗，线下会将所有教师资格证、学信网信息展示在机构大厅，但凡不敢展示的机构都是吹嘘作假；
- 教师详细资质可在系统「教师信息」页面查询，并支持通过学信网在线核实；
- 不只看学历，更重视老师是否真正会教、是否有责任心、是否能关注学生课堂状态。

### 3. 小班教学：每班约 10 人，至少 四名老师陪学

- 每班严格控制约 10 名学生，保障每个孩子都被看见；
- 每个班级配备至少 4 名老师参与教学与辅导；
- 管理员不定时查岗，关注教师上课状态、课堂秩序和学生学习情况；
- 坚守「没有学不会的学生，只有不会教的老师」，每一位学生都是重点关注对象。

### 4. 管理透明：自研教务系统，家长实时可查

- 独立开发的教务管理系统，管理端、教师端、家长端三端全覆盖；
- 家长可实时查看孩子的课程安排、到校考勤、课堂反馈、任课老师信息、剩余课时等；
- 寒暑假时间集中，家长最关心的「是否安全到校、是否认真上课、老师是否关注」都能通过系统随时掌握，少焦虑、少反复询问。

### 5. 价格透明：高性价比，无二次收费

- 新乐范围内高性价比收费，力求让家长每一分钱都花在刀刃上；
- 所有教辅材料包含在内，无隐性消费、无二次收费；
- 配套新乐本地定制的志愿填报系统，免费使用，可精准匹配高中志愿。

### 6. 服务延伸：AI 智学 + 权益体系，课后也能继续学

- **7×24 小时 AI 智学中心**：汇聚 DeepSeek、MiMo、Kimi 多个大模型，随时提供题目解析、知识梳理、拍照解题；
- **假期作业免费打印**：每名学生可免费打印暑假作业（普通 80 张，VIP 300 张，SVIP 500 张）；
- **阶段学习报告**：每学期末汇总出勤、课堂表现与阶段反馈，VIP 升级为月度报告；
- **赠送一对一辅导**：VIP 赠送 1 小时、SVIP 赠送 3 小时，集中处理薄弱环节；
- **老带新回馈**：成功推荐新生报名可享学费抵扣等专属回馈。
