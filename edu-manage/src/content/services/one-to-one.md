# 牧哲学堂 · 各年级一对一冲刺课程优势说明

> 牧哲学堂一对一（个性化）课程面向各年级学生，由经验教师一对一授课，结合自研教务系统的课堂反馈、学情报告与成长档案，让每一次冲刺都**看得见、留得下、追得上**。

---

## 一、及时反馈：课后即反馈，家长当天掌握学习情况

- **结构化课堂反馈**：每节课后，老师按照「课堂表现 → 知识掌握 → 存在问题 → 后续建议」四个维度提交反馈，家长课后即可查看；
- **AI 辅助生成**：系统结合本节课授课内容与课堂状态，AI 自动整理知识点、表现标签和下一步建议，反馈更完整、更专业；
- **家长端实时查看**：到课情况、课堂反馈、任课老师评价实时同步，家长不用反复询问老师，随时打开手机就能了解孩子状态；
- **有问题当天解决**：反馈中记录的薄弱环节会在下一节课重点回顾，问题不留到明天。

## 二、完整学情报告：进步看得见，数据会说话

- **一键生成 PDF 学情报告**：支持每周查看并下载，打印留存都方便；
- **核心数据一目了然**：出勤率、课堂反馈条数、个性化授课时长、剩余课时；
- **成绩趋势可视化**：各学科成绩趋势图，孩子的进步曲线清清楚楚；
- **知识掌握量化**：已掌握 / 需复习 / 薄弱知识点占比，薄弱点精确到具体知识点；
- **阶段学习报告**：学期末自动汇总出勤、课堂表现与阶段反馈（VIP 升级为月度报告，SVIP 提供考后即时分析 + 深度报告）。

## 三、今天孩子学了什么：清清楚楚、明明白白

- **授课内容留档**：每节课记录「本节授课内容」——讲授的章节、知识点、做的例题与练习，家长随时可查；
- **「老师最近说」**：家长端成长主页展示老师最新反馈与评价，孩子今天学得怎么样，一眼看懂；
- **各科老师本期评价**：按学科汇总任课老师本期点评，覆盖学科、评价次数、最近反馈时间一目了然；
- **作业与练习同步**：课堂练习完成情况、作业任务一并记录，家长清楚知道课后该配合什么。

## 四、学习留痕：学过的知识不丢，成长轨迹可追溯

- **成长时间线**：课堂反馈、成绩、成长动态按时间排列，随时回看孩子的学习变化；
- **知识点留痕**：每个知识点标记掌握状态，薄弱知识点自动累计错误次数，反复巩固直到掌握；
- **亮点沉淀**：表现标签、徽章、表扬记录自动沉淀为「本期亮点」，孩子的每一点进步都被看见；
- **学习目标跟踪**：目标设定与达成进度可视化，冲刺进度家长全程可见。

## 五、一对一老师：经验丰富、资质可查、管理严格

- **师资背景扎实**：授课教师均为 211/985 高校硕士研究生，持教师资格证上岗，具备丰富的一线教学经验；
- **资质公开可查**：教师详细资质在系统「教师信息」页可查询，支持学信网在线核实，家长放心；
- **按年级配置**：一对一课程按年级独立配置教师与定价，匹配对应学段的冲刺需求；
- **全程管理**：一对一约课由教师提交、管理员审核，审核通过才累计课时；管理员巡课查岗，教学质量有保障。

## 六、一对一冲刺：为孩子量身定制学习规划

- **先诊断、后规划**：结合孩子的学习基础、薄弱环节和目标学段，制定个性化冲刺方案，拒绝千篇一律；
- **目标导向**：围绕升学衔接、冲刺、选科和高考规划设定阶段目标，逐项跟踪达成；
- **灵活约课**：一对一 / 一对二 / 一对三按实际授课累计课时，时间安排灵活，冲刺节奏自主掌控；
- **薄弱点集中突破**：一对一授课聚焦孩子最需要提升的知识点，把时间花在刀刃上，提分效率更高；
- **全程陪伴**：主教师全程跟进，配合家长端实时反馈与阶段报告，家校协同冲刺。

## 附：一对一冲刺 vs 大班课对比

| 对比维度 | 一对一冲刺 | 普通班课 |
| ---- | ---- | ---- |
| 教学针对性 | 按孩子情况定制，只讲薄弱点 | 统一进度 |
| 反馈及时性 | 每课后结构化反馈 + AI 建议 | 反馈周期较长 |
| 学情可视化 | 学情报告 PDF + 成绩趋势图 | 阶段总结为主 |
| 学习留痕 | 时间线 + 知识点留痕 + 目标跟踪 | 记录较简 |
| 师资配置 | 经验教师 1 对 1 | 1 师对多人 |
| 时间安排 | 灵活约课，按实际课时累计 | 固定课表 |
| 课后服务 | 家长端实时可查 + 阶段报告 | 基础通知 |
