## 加速原理

- 引擎数据盘在 D 盘 → 镜像层缓存、npm 依赖层缓存重启后保留。
- 只改业务代码时，`docker build` 的 base/deps 层直接命中缓存，**只需重新编译 Next.js（约 8-12 分钟）**，不需要重新 `npm ci`。
- 上传用裸 tar（勿用 Windows `tar -czf` 再包一层，docker load 会报 `unrecognized image format`）。

## 部署五步（每次约 15 分钟）

### 1. 启动 Docker Desktop 并等引擎
```powershell
Start-Process "C:\Users\Administrator\AppData\Local\Programs\DockerDesktop\Docker Desktop.exe"
$docker = "C:\Users\Administrator\AppData\Local\Programs\DockerDesktop\resources\bin\docker.exe"
& $docker version --format "{{.Server.Version}}"   # 返回 29.4.0 即就绪
```
> 注意：引擎偶尔启动即退出，若断连就重新 Start-Process 一次；构建期间勿关闭 Docker Desktop。

### 2. 构建镜像（复用缓存）
```powershell
cd "D:\01muzhexuetang\muzhexuetang\coding\edu-manage"
& $docker build --target runner -t edu-manage-app:fix-v4-<日期> . *> release\build.log 2>&1
Get-Content release\build.log -Tail 3   # 看到 "Successfully tagged" 即成功
```

### 3. 导出并上传（裸 tar，勿 gzip 二次打包）
```powershell
cd release
& $docker save edu-manage-app:fix-v4-<日期> -o edu-manage-app-fix-v4-<日期>.tar
scp -i "C:\Users\Administrator\.ssh\id_rsa" edu-manage-app-fix-v4-<日期>.tar root@101.200.191.201:/opt/edu-manage-docker/source/release/
```

### 4. 服务器加载 + 切换（含回滚备份）
```bash
# 在服务器上（或 ssh 执行）
docker tag edu-manage-app:latest edu-manage-app:pre-<日期>-backup   # 备份当前
docker load -i /opt/edu-manage-docker/source/release/edu-manage-app-fix-v4-<日期>.tar
docker tag edu-manage-app:fix-v4-<日期> edu-manage-app:latest
cd /opt/edu-manage-docker/source && docker compose -f compose.production.yaml up -d app
docker compose -f compose.production.yaml ps   # 等 app 变 healthy
```

### 5. 验证
```powershell
curl.exe -s -o NUL -w "HTTP %{http_code}" https://muzhexuetang.xyz/
# 业务修复验证：镜像内检索编译产物特征字符串
docker run --rm --entrypoint sh edu-manage-app:latest -c "grep -rl '<修复文案>' /app/.next | head -2"
```

## 回滚（秒级）
```bash
docker tag edu-manage-app:pre-<日期>-backup edu-manage-app:latest
cd /opt/edu-manage-docker/source && docker compose -f compose.production.yaml up -d app
```

## 常见坑
1. **Windows tar 二次打包**：`tar -czf x.tar.gz x.tar` 会套一层归档 → docker load 报 `unrecognized image format`。直接传裸 `.tar`。
2. **PowerShell 转义**：远程命令含引号时用 paramiko/Python 脚本执行，避免 PowerShell 解析 `\"` 和 `|`。
3. **Docker 引擎闪退**：启动后 1-2 分钟内再次 `docker version` 确认；构建放后台并写日志文件。
4. **注释不入产物**：镜像内验证特征用 JSX 文案 / 字符串字面量（如"仅展示本月有课时的同学"），不要用代码注释。
