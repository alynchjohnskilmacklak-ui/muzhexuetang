# 小牧 AI 助手 · 全新设计 v3（电脑 + 手机双端）

> 摒弃旧版思路重新设计。三个核心命题：
> 1. **美感** —— 高级感、舒适、品牌统一（深绿 × 米白 × 驼金）
> 2. **信息汇总** —— 打开助手第一屏就是"我的今日"全量汇总，不用翻页面
> 3. **意图控制操作** —— AI 不止聊天，能听懂"帮我…"并真正执行（跳转/查询/操作，需确认）

---

## 0. 设计语言（美感规范）

| 项 | 值 |
|---|---|
| 主色（品牌深绿） | `#0E3B2E` |
| 辅助绿 | `#1D6A50` |
| 底色（米白） | `#FAF7F1` |
| 弹窗面（暖白） | `#FFFDF9` |
| 强调（驼金） | `#B4652E` |
| 提醒（珊瑚） | `#E8784A` |
| 文字主/次/弱 | `#1A1201` / `#6B6257` / `#9A9083` |
| 圆角 | 卡片 14 / 弹窗 24 / 按钮全圆 |
| 阴影 | `0 24px 64px rgba(14,59,46,.18)` |
| 遮罩 | `rgba(14,59,46,.42)` + `blur(6px)` |
| 动效 | 240ms `cubic-bezier(.2,0,0,1)`；`prefers-reduced-motion` 全关 |
| 字体 | 标题 16–20/600，正文 14/400，辅助 12/400；数字 `tabular-nums` |

**审美要点**：留白优先（卡片间距 12–16）、一层阴影一层质感（不堆边框）、小羊插画作为唯一装饰角色、强调色只用于"可点"与"提醒"，不做大面积撞色。

## 1. 三屏结构（双端统一：居中弹窗，电脑 480×640 / 手机 92vw×88dvh）

```
┌ 遮罩（blur 6px · 点击关闭）───────────────────────┐
│  ┌──────────────────────────────────────────┐  │
│  │ ① 头部：小羊头像 · 小牧 AI 助手 · 在线点   ·  最小化  关闭 │ 44px
│  ├──────────────────────────────────────────┤  │
│  │ ② Tab 栏：[ 今日汇总 ] [ 问 AI 办事 ]      │ 44px │
│  ├──────────────────────────────────────────┤  │
│  │ ③ 内容区（flex:1 内部滚动）                │  │
│  │   · Tab1 今日汇总：                        │  │
│  │     问候+天气 ─ 四指标卡 ─ 动态流 ─ 周摘要  │  │
│  │   · Tab2 问AI办事：建议意图chips ─ 对话流  │  │
│  │     （含"意图操作卡"）                     │  │
│  ├──────────────────────────────────────────┤  │
│  │ ④ 快捷指令宫格（常驻底部，6 宫格）          │ 56px │
│  └──────────────────────────────────────────┘  │
└───────────────────────────────────────────────┘
```

- 定位：水平垂直居中；宽 `min(480px, 100vw-32)`；高 `min(640px, 100dvh-48)`。
- 打开/关闭：遮罩点击、Esc、头部关闭按钮；打开时 body 锁滚动，焦点入弹窗，关闭焦点回球。
- **快捷指令宫格常驻底部**（不进 Tab），六个入口一眼可达——这是"操作效率"的关键。

### 手机端（居中弹窗 92vw × 88dvh）

```
┌ 遮罩（点击关闭 · blur 6px）──────────────┐
│ ┌──────── 居中弹窗 ────────────────┐ │
│ │ ① 头部：小羊 · 小牧 AI 助手 · 在线点  ✕ │ 40px
│ ├ Tab 栏：[ 今日汇总 ] [ 问 AI 办事 ]     │ 40px
│ ├ 内容区（内部滚动，safe-area 底部）       │
│ │   · 今日汇总：问候/天气 → 四指标 → 动态流 │
│ │   · 问AI办事：chips → 对话 → 操作卡确认  │
│ ├ 快捷指令宫格（2×3，与内容区分区）        │
│ └──────── 底部圆角安全区 ──────────┘ │
└──────────────────────────────────────┘
```

- **双端同一套组件**，仅尺寸/间距响应式：电脑 480×640，手机 `min(92vw,400px)×min(88dvh,720px)`，均水平垂直居中、圆角 24、同一遮罩规范——观感一致，无底部抽屉。

## 2. 信息汇总体系（第一个 Tab「今日汇总」）

打开助手**零操作**即见系统聚合结果，按角色渲染：

| 区块 | 内容 | 家长 | 教师 | 管理 |
|---|---|---|---|---|
| 问候 | 名字 + 时段问候 + 一句话今日重点 | ✅ | ✅ | ✅ |
| 天气 | 本地天气 + 提醒（给娃添衣/路上注意） | ✅ | ✅ | ✅ |
| 四指标卡 | 今日课次/出勤/待办/未读 | ✅ | ✅ | ✅ |
| 动态流 | 课堂反馈 > 留言回复 > 通知公告 > 考勤 > 缴费，每类最多 2 条 | ✅ | ✅ | ✅ |
| 周摘要 | 「本周 3 次课 · 出勤 3/3 · 5 条反馈 · 剩 8 课时」一句话聚合 | ✅ | ✅ | 校区周况 |

- 动态卡：类型图标 + 标题 + 摘要 1 行 + 时间 + 未读红点；**点卡跳详情并已读**。
- 数据源：现有简报接口 + 未读数接口合并，新增 `/api/ai/weekly-summary` 供周摘要。
- 汇总刷新：打开时强制刷新；面板停留时 60s 轮询；有新增 → 顶部提示条「有 N 条新动态，点击刷新」。

## 3. 意图识别与控制操作（第二个 Tab「问 AI 办事」）——本设计核心

### 3.1 三层能力

| 层 | 能力 | 示例 |
|---|---|---|
| L1 汇总 | 系统自动聚合（见第 2 节） | 打开即见 |
| L2 问答 | 自然语言 → 意图识别 → 结构化回答 | "他这周考勤怎么样" → 考勤摘要卡 |
| L3 操作 | 识别操作意图 → 生成**意图操作卡** → 用户确认 → 执行 | "帮我把今天的反馈发给我" → 卡片确认 → 发送 |

### 3.2 意图类型与响应

| 意图类型 | 触发语示例 | AI 响应形态 |
|---|---|---|
| 查询 | 考勤/课表/反馈/缴费/课时 | 数据摘要卡（结构化字段，点卡进详情） |
| 导航 | 去通知中心/打开课堂反馈 | 直接跳转（带 200ms 过渡提示） |
| 操作（需确认） | 发送通知/生成简报/标记已读 | **意图操作卡**：动作 + 对象 + 参数预览 + [确认执行][取消] |
| 闲聊/咨询 | 机构/课程/政策 | 普通对话回答 |

### 3.3 意图操作卡（关键交互）

```
┌──────────────────────────────────┐
│ ⚙ AI 已理解你的意图               │
│ 动作：向「任泓涛家长」发送今日反馈  │
│ 内容预览：3 条课堂反馈 + 1 条留言   │
│ 发送渠道：站内通知（企微群发另确认） │
│ ┌─────────┐ ┌─────┐              │
│ │ 确认执行 │ │ 取消 │              │
│ └─────────┘ └─────┘              │
└──────────────────────────────────┘
```

- 实现：对话流中 AI 返回结构化 JSON（`{intent, type, payload}`），前端渲染为卡片；
- 确认前可改参数（对象/时间范围）；执行后卡片变「✅ 已执行 10:32」留痕；
- 危险操作（群发、删除）强制二次确认 + 弹窗级提示；
- 手机端：操作卡点开为**全屏确认页**（防误触）。

### 3.4 上下文与多轮

- 记住对话内的指代（"他"= 当前孩子 / "这周"= 最近 7 天）；
- 建议意图 chips：按角色给 6 个高频（家长：看今天动态/查本周考勤/催缴提醒/联系老师/看课表/查剩余课时；管理：看今日待办/生成运营简报/查某学员课时/发送通知）；
- 会话历史保留 20 轮，可一键清空。

### 3.5 精细化细节（对话与操作）

- **打字机流式输出** + 随时可打断（停止按钮）；
- 回答带**证据入口**：数据类回答底部附「查看详情 →」直接进对应页；
- 意图识别失败时**追问一次**（"你是想看考勤还是课表？"），不瞎猜；
- 操作卡分级确认：普通操作 1 次确认；**群发/删除类红色双确认**；
- 执行结果留痕：卡变「✅ 已执行 10:32 · 查看记录」；
- **常用意图记忆**：重复 3 次以上的操作（如"看今日动态"）自动进快捷宫格第 2 位；

## 4. 快捷指令宫格（常驻底部）

| 家长 | 教师 | 管理 |
|---|---|---|
| 课堂反馈 | 今日课程 | 学员管理 |
| 家校沟通 | 考勤打卡 | 教师管理 |
| 缴费明细 | 我的反馈 | 考勤审核 |
| 每日练习 | 家校消息 | 课堂反馈 |
| 课程表 | 课时工资 | 缴费管理 |
| 通知中心 | 通知中心 | 通知中心 |

宫格（精细化）：
- 每个入口 = **图标 40px + 主标签 12px/600 + 副文案 10px/400**（家长端如「课堂反馈 · 老师动态」「家校沟通 · 留言回复」「缴费明细 · 课时余额」）；
- 带**动态角标**：该入口有未读时右上角珊瑚小圆点（反馈/通知类）；
- 分组展示：第 1 组「常看」4 个 + 第 2 组「系统」2 个（通知中心/更多），间距 12px；
- 热区 ≥44px；点按 `scale(.96)` + 120ms；手机端宫格 2×3 平铺，电脑 1 行 6 列；
- 支持**最近常用自动置顶**（localStorage 记录点击次数，第 1 位显示"最近在用"）。

## 5. 提醒体系（收起态，手机/电脑共用）

1. **未读角标**：球右上角数字（≤99+），数据 `/api/parent/unread-counts`；
2. **提示气泡**（本会话只主动弹 1 次）：标题「小牧今日提示」+ 一句话重点 + 最近 1~2 条动态卡 + 「查看全部动态→」+ × 关闭；点卡片直达并已读；
3. **重要横幅**：公告/考勤异常时球上方滑出 8s 横条（最高优先级，与气泡互斥）；
4. **每日首次摘要**：当天首次进入系统自动展开一次「今日汇总」；
5. **免打扰**：默认 22:00–07:00 不弹气泡/横幅，仅留角标（可在设置中改）。

---

## 6. 交互与无障碍

- 键盘：Esc 关闭；Tab 顺序 头部→Tab→内容→宫格→关闭；焦点管理；
- 动效降级 `prefers-reduced-motion`；遮罩 blur 不降级（仅视觉）；
- aria：球/关闭/发送/确认均有 label；弹窗 `role="dialog" aria-modal`；操作卡执行有结果播报（role=status）。
