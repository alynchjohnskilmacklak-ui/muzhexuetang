# 七年级上册背词库入库设计

## 目标

把用户提供的 9 张人教版七年级上册词汇页整理成可练习的数据库词条，并让家长端词表、出题和判分使用同一份入库数据。

## 数据口径

- 包含图片中 Starter Unit 1–3、Unit 1–7，以及 Reference Word List 的基数词、序数词、月份和星期。
- 每个单元中的词条按“年级 + 册别 + 单元 + 词头”区分；同单元同词头合并多词性和多义项，不跨单元合并。
- 保留教材正文页码和词表页码；复数、第三人称、拼写变体及括号说明保存在词条备注中。音标是可选字段，无法可靠辨认时不补猜测。
- 将现有 202 条静态词条一并迁入数据库；旧词条 ID 保持不变，以维持 `VocabProgress` 的关联。
- 导入采用 upsert，不删除任何现有词条；重复执行不会增加重复行。

## 方案

新增 `VocabWord` 表，包含现有背词模型所需字段和教材页码，并以 `(grade, volume, unit, headword)` 建唯一约束。教材词表作为可审查的数据文件保存，导入脚本将旧词表与教材页合并后写入数据库。家长端三个词汇 API 从数据库加载词条，学习进度和历史练习仍沿用现有表与 ID。

## 验收

- 词表数据测试检查各单元覆盖、参考词表范围、字段非空和单元内无重复。
- 导入测试检查保留旧 ID、同词条合并且不会丢释义。
- 目标数据库确认是 loopback 上的本地 `edu_manage` 后才运行入库脚本。
- 入库后核对总量、分组数量、重复数、遗漏哨兵词和重跑幂等性；再运行背词相关测试及类型检查。
- 不触碰生产库，不清理或重置数据库，不改写学习进度和练习历史。
