# 七年级下册背词库入库实施计划

**目标：** 将用户提供的《人教版七年级英语下册》词汇索引第 97–105 页（源图片文件 105–113）的全部词目导入本地 `edu_manage`，并让家长端能选七年级下册练习、记录成绩和复习错词。

**边界：** 保留七上词库、现有学习进度和练习记录；只操作本机 `edu_manage`，不修改生产库；不改主题和会员等级视觉。

## 任务

1. 先写词表测试：按 Unit 1–8、源页、关键短语/专名核对数量；检查词性、释义、稳定 ID 和无重复。
2. 新增七下结构化词表和只写七下词条的本地幂等导入脚本。
3. 将册别贯通家长端：册别选择、出题、阅卷及练习记录均使用同一 `grade + volume`，避免下册答案被按上册校验或记录。
4. 导入本地数据库两次验证幂等；通过家长端实际使用的读取函数核对册别、源页和 Unit 计数。
5. 运行定向/全量测试、类型检查、改动文件 ESLint 和生产构建；核对没有改动学生历史进度。

## 验收

- 七下源页 97–105 均有词条；Unit 1–8 及短语/专名覆盖经逐页比对。
- 七上记录数量与进度完全不变；七下导入重复运行不新增重复行。
- 七下可在家长端选择；出题范围和 `VocabSession.volume` 均为“下册”。
- 使用相同学习记录表，因词条 ID 含册别命名空间，七上/七下不会串词。
- 本地数据库验证、测试和构建结果如实记录。
