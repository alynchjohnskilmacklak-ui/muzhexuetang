# 小牧 AI 助手 · 全面重设计方案 v2

> 目标：在现有基础上（悬浮球拖拽/吸附、气泡预览、简报、快捷指令、对话）做**事无巨细**的功能与体验细化，并将展开弹窗改为**居中显示**。

---

## 0. 设计原则

1. **助手是"家里的常驻伙伴"**：默认收起在屏幕边缘，用角标+气泡悄悄提醒，不打扰；点开才是完整助手。
2. **三秒看懂今天**：展开第一屏 = 今日简报（考勤/反馈/通知/天气），不翻不找。
3. **一个入口通全部**：简报跳转、快捷指令、智能问答都从同一个悬浮球进。
4. **尊重系统**：`prefers-reduced-motion` 下关闭动画；键盘可完整操作；移动端与桌面端分别适配。

---

## 1. 悬浮球（小羊宠物）— 保留现状 + 细化

| 项 | 规格 |
|---|---|
| 尺寸 | 桌面 88px / 移动端 72px |
| 默认位置 | 右侧边缘收起（探出 44px 羊头），垂直居中偏下 |
| 拖拽 | 全屏自由拖拽（水平+垂直），Pointer Events，5px 阈值区分点击/拖拽 |
| 吸附 | 松手后按**最近边**吸附；左右边收起探头，上下边贴边完整显示；**绝不停在屏幕中间** |
| 收起态 | 羊头探出 + 侧边红点呼吸提示（有新动态时） |
| 未读角标 | 右上角红色数字气泡（≤99，99+ 显示"99+"）；仅家长端显示，数据源 `/api/parent/unread-counts` |
| 打开动画 | 点击 → 220ms 弹起（scale+translate，`cubic-bezier(.2,0,0,1)`）→ 弹窗入场 |
| 角色差异 | 三端同一只羊，但简报内容/快捷指令/角标数据按角色区分 |

**细化点**：
- 拖拽过程中球体加轻微缩放（1.05）+ 阴影，松手还原；
- 悬浮球在 hover 时羊头做一次轻抬头（桌面增强，无 motion 偏好时禁用）；
- 球不可遮挡：顶部避开导航栏（TOP_SAFE=72），移动端避开底部导航（BOTTOM_SAFE=96）。

## 2. 提醒体系（未展开时也要"会说话"）

### 2.1 未读角标（已有，保留）
- 数据：家长端未读数（反馈/留言/通知/公告汇总）。
- 刷新：页面聚焦时 + 每 60s 轮询 + 打开助手时强制刷新。

### 2.2 收起态气泡预览（已有，增强）
- 展示：最近 1~2 条高优先级动态（**老师反馈 > 留言回复 > 通知公告 > 考勤异常**），卡片式，跟随球的位置上下/左右自动翻转，永远不超出屏幕。
- 交互：点卡片 → 直接跳对应页面并标记已读；点「查看全部」→ 打开助手简报 Tab；右上角 × → 本次会话内不再显示（DISMISS）。
- 频控：同一会话只主动弹 1 次气泡；关掉后本轮不再自动弹（避免烦人）。

### 2.3 重要通知横幅（新增）
- 触发条件：**公告** 或 **考勤异常（缺勤/迟到）** 或 **课时扣减异常**，且未读。
- 形态：悬浮球上方 2s 内滑出的横条（最多同时 1 条，优先最新），点击跳转，自动 8s 收回，可手动关闭。
- 与气泡互斥：横幅在气泡之上，横幅未读时不弹气泡。

### 2.4 每日首次摘要（新增）
- 当天**首次进入系统**（localStorage 记录 `muzhe-ai-last-digest-YYYY-MM-DD`）且存在今日动态时，自动展开一次简报并定位到「今日简报」Tab；
- 已看过则不重复；可在助手设置里关闭"每日摘要"。

### 2.5 新动态实时提示（新增）
- 轮询 `/api/ai/unread-summary`（60s，页面隐藏时暂停，聚焦恢复立即查）；
- 检测到比上次更多的新动态 → 若悬浮球收起：先角标+1，再 2s 后弹气泡；若弹窗已开：简报 Tab 自动刷新 + 提示条「有 N 条新动态」。

### 2.6 免打扰（新增）
- 设置项：默认开启「22:00–07:00 免打扰」——期间不弹气泡/横幅/摘要，仅保留角标；
- 用户可自定义时段或一键关闭。

## 3. 展开弹窗 — 居中显示（本次核心变更）

### 3.1 桌面端（本次改为居中）

| 项 | 规格 |
|---|---|
| 定位 | **水平垂直居中**（`position:fixed; left:50%; top:50%; transform:translate(-50%,-50%)`） |
| 尺寸 | 宽 `min(460px, calc(100vw - 32px))`；高 `min(720px, calc(100dvh - 48px))` |
| 圆角 | 20px；头部顶部无圆角冲突 |
| 遮罩 | 全屏 `rgba(26,18,1,.4)` + `backdrop-filter: blur(2px)`，点击遮罩关闭 |
| 层级 | 遮罩 1090 < 弹窗 1100；悬浮球 1080（弹窗打开时球不可见或降为装饰） |
| 入场 | `opacity 0→1` + `scale .96→1` + `translateY(12px→0)`，240ms `cubic-bezier(.2,0,0,1)`；关闭反向，160ms |
| 背景滚动 | 打开时 `body overflow:hidden`，关闭恢复（已有） |
| Esc | 关闭弹窗并恢复焦点到悬浮球 |

### 3.2 移动端（保持底部抽屉）
- 全宽 `100vw`，底部弹起 `18px 圆角，顶部圆角`，`max-height: 94dvh`，带 `safe-area-inset-bottom`；
- 半屏遮罩；下拉小把手暗示可关闭（拖拽 60px 下滑关闭，可作增强）。

### 3.3 弹窗内部布局（自上而下）

```
┌────────────────────────────────────────────┐
│ 头部：小羊头像 · 小牧 AI 助手 · 在线圆点 · 最小化 · 关闭 │  ← 44px 高
├────────────────────────────────────────────┤
│ Tab 栏：[今日简报] [智能问答] [快捷入口]        │  ← 44px 高，选中态主题色下划线+滑块
├────────────────────────────────────────────┤
│ 内容区（flex:1，内部独立滚动）                 │
│  · Tab1 今日简报：问候语+动态卡列表+「查看全部」  │
│  · Tab2 智能问答：建议问题chips + 会话列表 + 输入 │
│  · Tab3 快捷入口：九宫格大图标入口              │
├────────────────────────────────────────────┤
│ 输入条（仅 Tab2）：输入框+发送按钮 · 语音(可选)  │
└────────────────────────────────────────────┘
```

## 4. 三个 Tab 的内容设计

### 4.1 Tab1「今日简报」
- 顶部问候：`「{名字}，晚上好 👋」` + 天气（已有 weather 数据）；
- 动态卡（3~5 张，按优先级排序，最多显示 5 条 + 「查看全部 N 条」）：
  | 卡类型 | 内容 | 跳转 |
  |---|---|---|
  | 课堂反馈 | 老师名 + 摘要 + 时间 | `/parent/class-feedback` |
  | 留言回复 | 回复内容摘录 | `/parent/messages` |
  | 通知公告 | 标题 + 摘要 | `/parent/notifications` |
  | 考勤动态 | 出勤/请假状态 + 课程 | `/parent/dashboard` |
  | 缴费提醒 | 到期提示 | `/parent/fees` |
- 卡交互：点击整卡跳转；右侧「已读/未读」圆点；无内容时显示空态插画+「今天一切正常，继续保持！」。

### 4.2 Tab2「智能问答」
- 顶部建议问题 chips（按角色 5~6 个，已有 ROLE_QUESTIONS）；
- 会话列表（已有 AIChatPanel，保留）：
  - 气泡式，AI 侧小羊头像，用户侧主题色；
  - 流式输出（已有）；
  - 支持 Markdown 轻渲染（加粗/列表/链接）；
  - 模型切换（已有 deepseek 等）；
- 底部输入条：输入框（多行自适应 1~4 行）+ 发送按钮（Enter 发送，Shift+Enter 换行）；字数上限 500；
- 历史会话：保留最近 N 轮（localStorage），「清空会话」按钮。

### 4.3 Tab3「快捷入口」（新增独立 Tab）
- 9 宫格大图标（4 列 × 2 行 + 收起提示），图标+文字，44×44 以上热区；
- 每端 6 个入口（沿用现有 QUICK_LINKS 数据）——从"常驻底部横滑条"升级为完整宫格，减少底部占用；
- 宫格下方保留「通知中心」聚合入口。

## 5. 交互与行为细节

| 场景 | 行为 |
|---|---|
| 点悬浮球 | 收起态→弹起→居中弹窗（桌面）/底部抽屉（移动） |
| 点遮罩 / Esc / 关闭按钮 | 弹窗 160ms 退场 → 球回到收起态（保留位置） |
| 最小化（新） | 弹窗收回，球保持展开态（露出完整），不收起 |
| 简报里点卡片 | 关闭弹窗 → router.push 目标页 → 对应未读数清零 |
| 对话中跳转（卡片链接） | 弹窗保留，新页签打开或同页跳转（按链接类型） |
| 焦点管理 | 打开时焦点入弹窗；Esc/关闭后焦点回球；弹窗内 Tab 顺序：头部→Tab栏→内容→输入→关闭 |
| 拖拽/吸附 | 保留现有逻辑（最近边吸附、不停中间） |
| 动效降级 | `@media (prefers-reduced-motion: reduce)` 全部动画 0ms |
| 无障碍 | 悬浮球/关闭/发送均有 aria-label；未读角标 aria-label；弹窗 role="dialog" aria-modal="true" |

## 8. 实施阶段（落地顺序）

- **阶段 1 · 弹窗居中化**：桌面弹窗改居中（定位/尺寸/遮罩/动效/焦点/Esc），移动端不变；弹窗内 Tab 栏接入现有三个内容模块。
- **阶段 2 · 快捷入口 Tab**：把底部横滑条升级为宫格 Tab，底部仅保留输入条（问答 Tab）。
- **阶段 3 · 提醒体系增强**：轮询 `/api/ai/unread-summary`、新动态提示条、重要通知横幅、每日首次摘要、免打扰设置。
- **阶段 4 · 打磨**：空态/加载态/错误态、动效降级、无障碍复核、多端多角色走查。
- 每阶段独立验证：`npx tsc --noEmit` + 本地三端实测（家长/教师/管理）+ 移动端 375px。

---

## 9. 不做的事（明确边界）

- 不做语音合成/语音识别（本期）；
- 不做多球/多主题皮肤（保持一只羊）；
- 不接第三方消息推送（提醒仅限站内）；
- 弹窗不做可拖拽（固定居中，保证可预期）。
