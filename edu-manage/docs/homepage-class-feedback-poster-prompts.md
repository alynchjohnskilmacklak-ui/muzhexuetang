# 首页课后反馈宣传图：GPT 生图指令

## 统一使用方式

每次先把牧哲学堂官方 Logo 图片作为参考图上传，再复制下面任意一条单图指令。每条指令单独生成一张 4:5 竖版宣传图，建议尺寸 1080 × 1350。六张图组成同一系列，但每张用不同的版式重心。

通用要求：采用牧哲学堂的暖米白、森林绿和克制的金色，少量暖橙作重点；字体清晰、留白充足、手机上易读。必须原样使用上传的官方 Logo，不重绘、不改字、不拉伸、不加假印章。人物使用背影、手部、插画或匿名化形象，不出现可识别的真实学生和教师。画面中的中文必须为简体中文且准确；只保留下方指定的短文案，不添加虚构数据、成绩提升、获奖、客户评价、师资承诺或招生承诺。对比部分写成“常见的单向反馈示意”，不指名、不贬低其他机构，并在底部标注“不同机构与课程的反馈方式各有差异，本图仅展示记录维度示意”。

## 1. 课后反馈不止一句话

生成一张 4:5 竖版教育服务对比海报，主题是“下课以后，家长看见什么”。上半部以克制的双栏呈现：左栏标题“单向沟通示意”，气泡里只有“今天表现不错，回家继续努力”；右栏标题“牧哲学堂课堂反馈”，用清晰的记录清单呈现“本节内容、课堂观察、知识掌握、回家巩固、下次关注”。右栏放官方牧哲学堂 Logo，左栏不出现真实机构名称或 Logo。主标题“课后反馈，不止一句‘今天表现不错’”。底部加统一说明“不同机构与课程的反馈方式各有差异，本图仅展示记录维度示意”。整体像高品质教育品牌编辑设计，温暖、可信、简洁，不做夸张对抗。

## 2. 这节课具体学了什么

生成一张 4:5 竖版教育品牌海报。视觉中心是一页整洁的匿名课堂记录，旁边是家长手机上清晰可读的反馈页面；记录以“本节学习内容”为核心，分出“课题、知识要点、课堂表现、练习建议”四个短栏。主标题“孩子学了什么，家长看得见”，副标题“把课堂重点整理清楚，让每次回看都有依据”。页脚使用官方牧哲学堂 Logo。页面内容仅作为功能示意，不展示真实姓名、头像、学校、成绩或联系方式。暖米白底、森林绿标题、金色细节，排版清楚，适合手机浏览。

## 3. 记录课堂过程，而非只给结论

生成一张 4:5 竖版教育品牌海报。用一段课堂场景插画或只表现老师手部、练习纸与笔的纪实风格照片，避免可识别面孔。画面把课堂观察整理为简洁标签：“主动表达”“思路梳理”“练习订正”“完成后检查”，每项旁边配克制的小图标。主标题“看见孩子在课堂里的每一步”，副标题“参与、练习与订正，都能成为下一次教学的参考”。右下角放官方牧哲学堂 Logo。不要分数、排名、效果承诺或虚构统计数字，整体温暖而专业。

## 4. 回家后怎样巩固

生成一张 4:5 竖版家校陪伴主题海报。用简洁清晰的三步流程表现家长如何陪伴复习：“怎么问：请孩子讲讲关键概念”“怎么练：完成一道同类题并说出思路”“怎么检查：核对步骤、订正易错点”。流程内容来自本节知识点讲解的延伸，表现为家长与孩子围桌看练习册的温馨场景，不出现可识别真人。主标题“回家复习，不必只问‘会了吗’”，副标题“给家长一个具体、可执行的陪学方向”。使用官方 Logo，暖米白、森林绿、少量金色，避免制造家长焦虑。

## 5. 课堂到下一次课的衔接

生成一张 4:5 竖版流程信息图，主题是“让每次课堂有后续”。用一条清晰、优雅的纵向路径连接四个节点：“本节课堂记录 → 个性化巩固建议 → 家长练习回传 → 下次课关注重点”。每个节点配一个简洁的线性图标和一句不超过 12 字的解释。主标题“课后有记录，下次有衔接”，副标题“老师与家长围绕同一份课堂信息继续跟进”。页脚放官方牧哲学堂 Logo。不要暗示自动诊断或保证成绩提升，风格简洁、有层次、容易一眼读懂。

## 6. 每一课沉淀为成长轨迹

生成一张 4:5 竖版成长档案宣传海报。画面像一页精致的学习记录时间轴，从“第 1 次课堂反馈”到“近期课堂反馈”逐条呈现知识点、学习状态、课堂照片缩略图占位和下一步关注；示例数据使用虚构课题，并清楚标注“页面示意”，不出现真实学生信息。主标题“把每次课堂，留成成长的足迹”，副标题“按课次回看内容、表现与后续安排”。加入官方牧哲学堂 Logo 和轻淡但清晰的品牌水印。不要分数排名、提升幅度、获奖或保证性结论。
