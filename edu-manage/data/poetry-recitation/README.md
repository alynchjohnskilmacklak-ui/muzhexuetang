## 单篇字段说明

- id：稳定唯一标识；新增内容时不要复用。
- sequence：本册展示顺序。
- title、author、dynasty：篇名、作者和朝代。
- textbookSection、contentType、genre：教材栏目、篇目类别和体裁。
- stanzas：按教材分段/联组织的原文；适合作为逐句背诵和默写单元。
- meaningSummary：简要理解提示。
- keyNotes：重点词语及释义。
- assignmentPolicy：默认由教师或学校按范围布置。
- crosswalk53：与 53 主册的逐篇对照结果、印刷页码和 PDF 页索引。
- textbookSource：教材 PDF 路径、PDF 页索引、印刷页码和定位状态。
- recordStatus：内容复核状态。

录入和复核时，原文文字以相应册别教材为准；默写判错应按用户确定的规则统计错字、漏字等文字错误，标点、空格和换行不作为独立错字。页面实现可使用 stanzas 保留原文行序，并依据 sequence 排序。

## 给页面实现的接入建议

推荐从 manifest.json 读取册别与文件索引，再加载对应册 JSON；也可直接用 all-items.json 做本地开发。页面侧不应把 matchedTo53MainBook=false 当作“不要求背诵”，也不应把全部条目默认标成必背。教师任务、学生完成记录、错字/漏字分项统计和班级错点分析属于运行时业务数据，应与本静态内容包分开存储。

## 来源

教材目录、篇目与 53 主册的匹配依据项目语文资料目录下已有的教材 PDF、教材篇目目录及逐篇对照报告。以各条目的 textbookSource、crosswalk53 和复核状态为准。九年级下册扫描页需要人工复核后再发布。
