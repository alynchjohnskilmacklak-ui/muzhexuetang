# 三端审查问题落实记录（2026-10-12）

本轮修改仅涉及本地代码，没有部署、执行数据库迁移、合并学员档案或写入生产业务记录。

## 已落实

1. 首页按身份保留所有授权历史 recordIds：反馈查询覆盖旧档案，出勤、徽章、最新反馈、当天反馈、课时比较及预习入口按代表孩子归并。未把同名档案自动视为同一个孩子。
2. 个性化课程详情使用统一家长孩子列表及历史记录范围，加入报名、课次、考勤与反馈软删除过滤；无效显式孩子链接不会默默展示另一个孩子。
3. 请假申请、站内通知和日志同事务保存。按语义请求键取得 PostgreSQL 事务锁，匹配已有有效申请时返回同一记录。通知查稳定 teacherId，覆盖课次教师、班级教师和主负责教师，不再拼姓名邮箱。未关联教师账号时明确提醒家长。
4. 成长档案 Hook 移至所有提前返回之前；焦点定位函数改为稳定回调并补全 effect 依赖、定时器清理；清理该页面两处 any 与错误 aria 属性。
5. 缴费页只有一套按身份 ID 的筛选，支持全部孩子和历史报名账单，金额与列表口径一致。模拟支付改为“咨询缴费方式”，明确不支持在线付款。
6. 沟通中心“家校公告”更名“课堂与档案评论”；保留隐藏 Tab，切换不再销毁表单组件。回复加载状态、网络失败提示和输入保留；标记、删除失败也有反馈。
7. 教师课表移除只有一项的 Tab 包装，保留原课表与旧入口。
8. 家长导航识别 tab 查询参数；孩子选择器只在支持全部聚合时显示“全部孩子”，移动点击区提升至44px；周报链接携带孩子 ID，使用 Next Link。
9. 家长布局请求统一 fetchJson，未读加载失败时提供重试入口，不把错误 JSON 解析为正常未读数据。
10. 学习资料默认紧凑列表，保留封面模式；预览/下载分开，增加键盘操作和44px触控区。没有删除任何资料或在线练习入口。
11. 报告打开时按授权范围加载本期完整反馈，不受页面时间线40条、日常反馈50条限制；普通档案请求仍使用原来的限制，避免日常加载变重。报告新增完整课堂反馈、知识点详解及全部课堂照片，沿用现有公式渲染组件。
12. PDF 改为逐章节/反馈区块渲染，按文本行、图片范围规划分页，避免整张长报告反复嵌入；照片加载失败或签名未完成时阻止导出缺图报告，并给出原因。
13. 管理/教师首页图表不再在 render 阶段写 ref，并在数据更新时实际更新图表；清理已审查的显式 any。

## 保留及未擅自执行的事项

- 历史同名档案需在管理端数据管理的“核对并关联学员身份”入口确认后关联；此入口原本已存在。本轮没有按姓名自动合并马紫晨、马子墨或其他学员，也没有删除历史数据。未确认的不同 identityId 仍可能显示为多个记录。
- 没有擅自隐藏晚托、升学、VIP等入口。按报名情况精简导航需要先确认产品规则，不用“没使用统计”推断功能没用。
- 原有等级主题及天气、AI、照片上传功能保留，没有全站换色或大规模重排首页。
- 不同报告调用端暂未整体迁移成唯一导出引擎。本轮先修家长报告缺内容与分页；管理端既有完整报告导出保留。
- 开始核查时工作区已有大量未提交修改，本轮只改上述相关功能；没有回退用户原有改动。

- TypeScript 类型检查通过。
- Vitest：127个文件，558项测试通过；相对审查时新增10项（请假3、首页聚合1、分页/导航6）。
