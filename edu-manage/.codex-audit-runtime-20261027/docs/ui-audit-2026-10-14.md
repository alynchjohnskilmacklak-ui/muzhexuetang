# 牧哲学堂全站 UI 审查（2026-10-14）

## 审查范围

- 内置 Browser 的教师端窄屏页面，视口约 385 px 宽：家校沟通列表、教师首页首屏和下半屏、考勤录入、教师功能菜单、VIP 课程预约。
- 共享教师/家长移动壳、管理端主壳、颜色 token、按钮和头像组件，以及管理端沟通中心的静态实现。
- 只做页面浏览与代码只读检查，没有回复消息、提交考勤、预约课程、上传文件或修改业务数据。

## 页面步骤与健康度

1. **教师端家校沟通列表：整体良好。** 卡片包含头像、年级、家长关系、学科和消息预览；整页没有观察到横向溢出，截图中的头像均正常显示。日期、标签和次要说明字号偏小、颜色偏浅。
2. **教师首页首屏：整体良好，有遮挡与可读性问题。** 欢迎区、指标、今日课程和快捷入口层次清楚；图表刻度偏小，右侧悬浮助手和开发调试浮层会挤占内容/遮住底栏入口。
3. **教师首页下半屏：基本良好。** 周进度、课酬和教学概览结构清楚；移动端图表轴文字仍偏小，右下角悬浮控件与底栏区域容易争夺注意力。
4. **考勤录入：基本良好。** 当前无分配班级时显示了明确的空状态和下一步说明；橙色选中按钮上的白字对比不足。当前页面未显示学生数据，不能评价逐人考勤卡片。
5. **教师功能菜单：良好。** 分组与当前项清晰、关闭入口明确，窄屏下菜单可读；菜单打开时右侧仍露出悬浮助手，底部仍能看到本地开发调试浮层。
6. **教师 VIP 课程预约：本轮未能完成视觉核验。** 页面连续截图仍是骨架屏；后续浏览器页面切换也出现响应延迟。无法据此判断是接口慢、开发服务器忙还是浏览器控制延迟，但页面需要可见的超时/重试反馈。
7. **家长端与管理端页面：未作运行时截图核验。** 当前浏览器保持教师身份，没有切换身份或借用其他账号；家长端/管理端结论只来自共享布局与源码检查。管理端沟通中心的窄屏标签状态需要有管理端会话后再看实际页面。

## 已确认的优点

- 暖色浅底、白色卡片、墨绿导航和橙色主操作保持了牧哲学堂的整体风格；主要标题和正文使用深色，截图中阅读层次自然。
- 教师留言列表卡片整块可访问，辅助树给出了含学生上下文的按钮标签；截图里头像、消息卡片和等级/学科标签均已正常呈现。
- 考勤空状态讲清楚了当前没有班级以及需要管理员分配，减少了用户误以为页面坏掉的情况。
- `StudentAvatar` 使用本地男女默认头像，`CachedAvatarImage` 处理网络头像加载失败；本地默认头像资源存在。常见网络头像失效时有回退路径。
- 移动端壳给底部导航预留了内容空间并考虑安全区，当前实拍页面未见横向滚动。

## 主要风险

### P1：主色按钮和消息文字对比度不足

按截图/源码颜色计算，普通小字对比度低于 WCAG AA 常规文本的 4.5:1：

| 文字 / 背景 | 对比度 | 审查结果 |
|---|---:|---|
| 白字 / 主橙 `#E8784A` | 2.91:1 | 不足；考勤选中项和常见主按钮需要优先处理 |
| 白字 / 教师消息绿 `#1D9E75` | 3.39:1 | 不足；14 px 聊天气泡文字风险较高 |
| 次要字 `#9A8E7A` / 白底 | 3.22:1 | 不足；11 px 时间戳/元信息尤为明显 |
| 图表字 `#8D806F` / 白底 | 3.85:1 | 不足；且轴标签仅 11 px |
| 主正文 `#1A1201` / `#FAF8F5` | 17.52:1 | 良好 |
| 米白 `#F6E9C8` / 墨绿 `#0D392F` | 10.59:1 | 良好 |

对应实现位于 [globals.css](../src/app/globals.css#L11)、[teacher/messages/client.tsx](../src/app/teacher/messages/client.tsx#L54) 和 [teacher/dashboard/page.tsx](../src/app/teacher/dashboard/page.tsx#L207)。建议保留品牌色相，给主按钮和教师气泡增加更深的文本/背景 token；次要文字不要只靠降低透明度来分层。

### P1：默认按钮和输入框触控高度没有统一到移动目标

全局 `.ant-btn` 最小高度在样式表中出现 36 px 和 38 px 两组声明，输入/选择控件为 42 px；部分预约、反馈和材料页面又单独覆写成 44–46 px。造成不同模块按钮手感不一致，部分默认按钮仍小于项目移动端 44 px 目标。见 [globals.css](../src/app/globals.css#L311) 与 [MobileLayout.tsx](../src/components/Layout/MobileLayout.tsx#L479)。建议统一按钮、图标按钮、输入框和下拉框的最小触控尺寸，并检查相邻按钮间距；紧凑场景也至少保证清晰可点的命中区域。

### P1：VIP 页面慢请求时只有骨架屏，没有可见的等待上限

本轮 `/teacher/intensive` 连续采集到的画面仍是骨架屏。源码显示 `isLoading` 时直接返回十行骨架；页面错误提示在后续主页面中，因此请求长期悬挂时用户看不到错误或重试入口。该页还每 5 秒重新校验一次数据，可能增加繁忙时的请求与刷新压力，但本次没有测出实际卡顿原因。见 [teacher/intensive/page.tsx](../src/app/teacher/intensive/page.tsx#L159)、[loading 分支](../src/app/teacher/intensive/page.tsx#L335) 和 [错误提示](../src/app/teacher/intensive/page.tsx#L437)。建议设置清晰的加载超时、重试按钮和保留页面上下文的错误状态，并评估 5 秒轮询是否必要。

### P2：悬浮助手的“露边”状态触控区偏小且覆盖内容

助手按钮直径 52 px；收起露边时 `right` 会设成 `-22 px`，屏幕内只露出约 30 px，低于 44 px 触控目标。教师留言和首页实拍中它压在内容右边缘，打开菜单时仍与抽屉同时出现。见 [AIFloatingLauncher.tsx](../src/components/AI/AIFloatingLauncher.tsx#L62) 和 [定位逻辑](../src/components/AI/AIFloatingLauncher.tsx#L159)。建议收起时仍保留至少 44×44 px 命中区，或移入菜单/底栏固定槽位，并保证它不会覆盖卡片关键文字。

### P2：本地开发浮层盖住底栏“更多”入口

教师首页实拍底栏右侧出现 Next.js `1 Issue` 红色浮层和 `N` 按钮，遮住/竞争“更多”入口。这属于本地开发工具，不应算作产品发布 UI 缺陷；但会干扰本地操作与视觉检查。需要先确认开发浮层的问题内容，并在正式 UI 审查时避免调试层挡住应用控件。

### P2：小号辅助文字和图表标注密度过高

留言卡片时间、部分标签说明为约 11–12 px；教师首页图表刻度/图例为 10–11 px。窄屏下仍能辨认，但阅读疲劳且与正文层级差距过大。建议元信息至少 12–13 px、提升对比度；图表减少次要标注、放大主要刻度，并避免同时压缩字体与间距。

### P2：移动断点解析期间会短暂输出空白壳

教师/家长壳在 `isMobile === null` 时只渲染空背景，管理端主壳直接 `return null`。本轮进入教师首页的第一次画面是空白，随后才出现内容；这与断点状态解析期间无占位内容的实现相符。见 [TeacherLayout.tsx](../src/components/Layout/TeacherLayout.tsx#L212)、[ParentLayout.tsx](../src/components/Layout/ParentLayout.tsx#L216)、[MainLayout.tsx](../src/components/Layout/MainLayout.tsx#L35)。建议使用同色系轻量壳/骨架作为初始内容，避免页面看起来像加载失败。

### P2：管理端沟通中心的窄屏标签未做显式适配

管理端沟通中心使用三个 Ant Design Tabs 标签，其中“课堂与档案评论”较长；组件没有针对手机屏宽缩短标签或显式布局。Ant Design 可能提供横向滚动，但管理端当前角色未开放，无法从本轮截图确认是否遮挡。见 [communication-center/page.tsx](../src/app/(main)/communication-center/page.tsx#L21)。建议在管理端窄屏实际确认标签滚动提示、首屏按钮可见性和弹窗宽度。

### P3：头像全部加载失败时会留空色块

学生头像组件会先尝试照片，再回退到本地性别默认图；若照片和默认图都失败，图片源会被移除，外层只剩浅色背景，没有姓名首字或通用占位图。见 [StudentAvatar.tsx](../src/components/Common/StudentAvatar.tsx#L19) 和 [CachedAvatarImage.tsx](../src/components/Common/CachedAvatarImage.tsx#L56)。本轮截图中的头像均正常，无实际裂图；建议为最后失败状态加姓名首字占位，确保异常时仍有身份线索。

## 建议修复顺序

1. 先统一色彩对比：按钮、聊天气泡和次要文字，随后用对比度检查复核白/橙、白/绿、灰/白组合。
2. 统一全局触控尺寸：把 Ant Design 默认按钮/输入下拉和自定义图标按钮统一到移动端目标，检查底栏和抽屉里的密集入口。
3. 给关键数据页补慢请求超时与重试，评估高频轮询；让骨架屏最终能转为可恢复错误状态。
4. 调整悬浮助手收起尺寸/定位，确保移动端菜单、底栏、浮层之间不遮挡。
5. 放大图表、时间戳和低优先级元信息；头像异常时提供文字占位。
6. 在具有管理端/家长端权限的会话中补做同一宽度实测，并增加平板、桌面、键盘焦点和页面缩放检查。

## 证据边界

- 本轮运行时证据仅来自教师身份和单一窄屏；没有切换角色，没有检查家长/管理端实际 DOM，也没有覆盖桌面、平板、键盘导航、200% 缩放或屏幕阅读器。
- 浏览器截图接口把截图显示在本轮对话中，但没有提供保存原始截图到工作区的能力；因此本文件保存了文字审查结果，页面截图留在本轮浏览器工具结果中，没有把含学生对话的截图另存进项目。
- VIP 页面骨架屏是本轮现场观察；未能区分接口响应、开发服务器或浏览器控制层造成的延迟，不据此归因后端故障。
