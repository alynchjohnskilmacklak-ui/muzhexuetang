# 家长端初中题库目录与发布标准

## 发布规则

家长端只显示 `src/data/published-practice-bank.ts` 导出的发布白名单。题组必须同时满足：

1. 与当前目录中的年级、学科、册次和目录路径完全对应；
2. 标明教材版本、目录来源和题目来源；
3. 每题有可用题干、答案、解析和知识点关联；
4. 题组标记为可发布，且无待审核标记。

未通过条件的旧题或来源题保存在审核候选数据中，不显示给家长。目录占位项只用于浏览教材结构，不作为题组或练习。

## 机构教材版本

本机构的初中目录按年级、学科、册次、教材目录顺序展示：

| 学科 | 版本 |
|---|---|
| 语文、英语、物理、化学、道德与法治、历史、地理 | 人教版；语文按统编教材目录 |
| 数学 | 冀教版 |
| 生物 | 冀少版 |

现行目录数据位于 `data/textbooks/current-junior-textbook-catalog-2026.json`，共 43 册。目录来源分别记录为出版社目录、本地现行教材或经核对的公开目录。九年级英语旧“全一册”不属于现行目录，不得发布到新版上下册。

教育部公布的修订教材自 2024 年起先在七年级使用，2025 年扩展至八年级，2026 年覆盖初中各年级；因此部分九年级新册次按已核对的新版目录和预排信息登记，不能把预排时间写成实体书版权页已确认。[教育部教材修订实施说明](https://www.moe.gov.cn/jyb_xwfb/s5147/202408/t20240828_1147579.html)

## 命题与核对要求

- 先将目录条目与课文、知识点对应，再按本节范围命题；不从章名直接扩写整章题目。
- 题目应原创，答案唯一或明确支持自我核对，并提供完整解析、知识点 ID 和来源引用。
- 数学、物理、化学需核查计算过程、单位、量纲和取值条件；英语需核查题目是否存在多个可接受答案；语文主观阅读题不得伪装成唯一答案；历史、道德与法治、地理、生物需核实版本和事实。
- 目录外、旧版专有内容、无法定位的题组不发布。能由当前目录和可靠材料重建的，按现行章节重写后再发布。
- 用户于 2026-10-13 明确表示题库审核完成并授权直接上架；当前通过发布规则的题组均记录审核人“用户确认”。

## 生产部署状态

生产上架使用项目唯一入口 `python deploy-release.py`：通过 Docker Buildx 构建镜像、上传并切换生产服务，再核对实际运行镜像、容器健康状态和 `/login` HTTP 200。用户已于 2026-10-13 授权直接上架；每次发布完成后以脚本的健康检查结果和版本标签为准。
