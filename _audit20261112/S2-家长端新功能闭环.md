#### 2.1.2 单词子模块链路标注

```
家长进入 /parent/vocab
  ├─ GET /api/parent/vocab?studentId=…            ✓ 家长身份 + 子女归属校验（findParentChild）；force-dynamic、no-store
  │    ├─ loadVocabEntries() 读 VocabWord 全量目录  ✓ 库内 2973 行，6 册分布齐全（见 2.8）
  │    ├─ vocabProgress.findMany(studentId in recordIds)  ✓ 进度按历史学籍 recordIds 收齐
  │    └─ vocabSession.findMany(take 10)  ✓ 最近场次回显
  ├─ GET /api/parent/vocab/deck?scope=new|review  ✓ 新学池=非 MASTERED；复习池=WRONG/LEARNING；seed 含 nonce 防同序
  │    └─ getVocabExpansion 静态扩展按词条命中      ✓ 扩展为构建期打包 JSON，不入库
  └─ POST /api/parent/vocab/session                ⚠ 半通：事务 + Serializable；submissionId 幂等见下
       ├─ 子女归属校验 + 词条归属校验（409 题目已更新）✓
       ├─ 幂等短路：submissionId 命中已有 Session → duplicate 直接返回，不重复 apply（session/route.ts:76-81,158-160）✓
       ├─ 逐词 upsert VocabProgress（历史快照 → applyVocabResult）✓
       └─ 建 VocabSession（含 answers 明细）          ✓
            ├─ 管理端 /api/admin/vocab-stats 读取      ✓ 本轮新确认：管理侧有读点（第六轮"管理侧孤岛"已部分变化）
            ├─ 教师端读取                              ✗ 0 读点
            └─ 周报 / 成长档案 / 家长看板读取          ✗ 0 读点
```

**⑤ 会话重试会不会重复计次（第六轮 P2 复核）**

- 服务端：幂等键 = `submissionId`（Session 主键），命中已有记录则短路、不再重复累加 Progress（`session/route.ts:76-81`）。
- 客户端：`submissionId` 在 `finishDeck` 内每次调用现场 `crypto.randomUUID()` 生成（`vocab/page.tsx:174`），**不跨重试持久化**（不存 localStorage/不随卡组保留）。
- 残留风险：若首条请求**已在服务端落库、但响应在网络层丢失**，家长点"重试"会带**新 UUID** 再提交一次 → 新建 Session 并再次 apply 进度（对错计数双加）。幂等键只防"同一 UUID 重放"，防不住"换 UUID 重试"。
- 库内旁证：4 场 Session 中，`…441e1`（11-05 13:17:36）与 `…86886e4`（11-05 13:21:52）同窗次（初一·上册·unit=null，total 16 / correct 5）相隔约 4 分 16 秒，形态高度疑似一次重试重复计次；另两场（11-09、11-10）为正常新学。

1. **教师端抽人写点是否真的写入 `ClassroomPick.parentVisible=true`**：本片只查读点；验法由 S1 核对 `POST/PATCH /api/teacher/interaction/pick` 写库字段，并用一条测试 pick 记录看家长 `/api/parent/interaction` 是否回显（验后删除测试记录）。
2. **教师端就餐视图是否读 `StudentMealAttendance`/`ParentMealChoice`**：本片仅确认管理端 summary 聚合；验法在 `src/app/teacher/**` 与 `api/teacher/**` grep `mealAttendance|mealChoice|MealReport`，对照教师就餐页读点。
3. **审批回写服务端规则**：ABSENT 分支、无课次单按日期翻转的具体实现与退费/课时扣减口径，归 S1 写点审查；验法 dry-run 重算 07-17、08-03 两单对应考勤。
4. **动词/语法/作文静态模块的题量与覆盖率**：本轮只确认"无表、无 API、localStorage"；未逐文件核对词条/语法点数量与大纲对齐情况，验法直接读 `src/data/english-{verbs,grammar,composition}` 导出常量。
5. **复习池长期命中率**：库内仅 1 生 32 条 Progress，WRONG 4 / LEARNING 23 样本不足；验法需在多生数据下观察 review 池规模与 ReviewStack 重答后状态变化。
6. **`archive/entry` localStorage 中转的健壮性**：直接 URL 进入、跨设备/清缓存后 `muzhe-archive-entry` 缺失时的空态表现，本片未走浏览器实测；验法在家长账号下直接访问 `/parent/archive/entry` 观察兜底。
7. **周报中是否应出现背单词/薄弱点**：本轮确认 `weekly-report/route.ts` 只读课次/考勤/成绩/通知/请假/反馈；产品上是否要纳入属拍板项，未做需求侧判断。
