## 0. 一句话结论

1. **归属校验总体到位**：按 `studentId` / 资源 id 读取档案、课时、考勤、试卷、反馈、表现动态的家长端路由，服务端均做了「当前家长名下孩子」复核（`findParentChild` / `parentLinkedStudentWhere` / `parentActiveStudentWhere` / `parentVisible*Where`），未发现可跨孩子直读档案或余额的接口。
2. **余额双口径分裂在家长端真实存在，且同一档案内两处口径不一致**：概览「累计课时」读 `Student.totalHours` 快照；「剩余课时」与课时明细行读 `Enrollment.remainHours/totalHours` 报名级；看板不展示余额。实测 **37 人快照正余额、报名级为 0**（复现 RO1 基线），151/191 名学生两级余额不一致。
3. **教师写入内容进入家长档案的口径共 7 类**：课堂反馈（ClassroomFeedback 已发布）、薄弱点（WeaknessRecord）、试卷题目掌握度（PaperQuestion.mastery）、表现动态（PerformancePost）、考勤（Attendance）、课时账（HourTransaction/Enrollment）、徽章/目标；**独立掌握度表 MasteryRecord 家长端无任何读点**，且库内缺 `termId` 列、写入即失败，是当前最大的「教师写了家长看不到」断点。
4. **解绑残留**：孩子解绑只清 `Student.parentId/parentUserId`，不归档历史通知、不撤会话；复核 **56 条脱节通知全部指向教师/管理员账号（teacher 46 / admin 10 / parent 0）**，当前家长账号名下未发现指向未绑定学员的遗留通知；看板通知列表的 where 比通知页弱（未套家长归属作用域），属潜在复现点。
5. **绑定/换绑**：`/parent/bind` 是纯展示页（读 `User.qywxExternalUserId`），绑定/解绑都在管理端 `/api/qywx/bind-management`；家长端孤儿路由 `/api/parent/wechat/unbind` 只清旧 WxPusher 的 `wxpusherUid`，不清企微字段。

**`archive/[id]` 与 `archive/entry` 分别是什么**

- `archive/[id]`：**试卷详情页**（ExamPaper + questions），服务端 `parentVisibleExamPaperWhere` 归属校验，不可达返回 404；无写动作。
- `archive/entry`：**时间线条目过渡详情页**，首屏数据从 `sessionStorage` 读取（`entry/client.tsx`），服务端不校验缓存条目归属；仅动态类型二次拉取 `/api/performance/[id]`（`parentVisiblePerformancePostWhere`），点赞走 `canAccessPost` 复核。直链无缓存时显示「记录不存在或已失效」。

### 2.4 个人资料：写表、同源性、孩子资料修改权限

- **家长自助可写字段**：仅密码。`POST /api/auth/change-password` → `User.password` 哈希 + 轮换 `currentSessionToken`（撤销旧会话）+ ActivityLog `PASSWORD_CHANGED_SELF`（`api/auth/change-password/route.ts:36-51`）。
- **姓名 / 电话 / 头像 / 关系**：家长端页面无编辑控件，`/api/parent/profile` 仅 GET（`api/parent/profile/route.ts:10`，无 PATCH/PUT/DELETE）；这些字段在 `User.name/phone/avatar`，由管理端维护。`/parent/profile` 页只读展示 `User.name/email/role/createdAt`（`profile/page.tsx:16-19`）。
- **孩子资料**：家长端不允许修改。`PATCH /api/students/[id]` 仅 `role === 'admin'`（`api/students/[id]/route.ts:266`）；字段白名单（:291-308）不含 `parentId/parentUserId`（教师 GET 另在 :242-243 把这两字段剥离），`parentName/parentPhone` 为 Student 快照字段，由管理端写入（:303-304）。
- **同源性**：管理端家长档案读 `User`；学生档案读 `Student`（含 parentName/parentPhone 快照）；家长端 profile 页同读 `User + Student`。**注意 Student.parentName/parentPhone 是快照**，与 User 账号姓名/电话不自动同步（与 O1 口径一致）。

### 2.5 教师列表：来源、换老师即时性、联系入口

- 来源：`Teacher` 表 `status ≠ 'RESIGNED'`（`teachers/page.tsx:14`），**全量在职名册**，不按当前家长名下孩子的报名班 / 任课关系过滤；附带每位教师 3 条已发布讲义。
- 换老师即时性：服务端每次请求实时读 Teacher 与 Enrollment/TeacherAssignment，**管理端改派后家长端下次刷新即变**；档案页/profile 页的「我的老师」才按 `mainTeacher + enrollment.group.teacher + teacherAssignments` 聚合（`profile/page.tsx:43-50`）。
- 联系入口：名册未 select `phone`（:15-30 字段清单无 phone），客户端无拨打 / 留言按钮；家长联系教师走 `/parent/messages`（留言分片，本片未展开）。
- 实测（`P4-sql-1.txt` Q4、`P4-sql-2.txt` I）：ACTIVE 教师 29（phone 全部有值）、RESIGNED 4（被过滤）。
