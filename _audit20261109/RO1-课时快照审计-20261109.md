# RO1 学生课时快照 vs 报名台账 一致性审计（只读）

- 执行时间：2026-11-09
- 命令：`npm run audit:hour-snapshots`（`edu-manage` 目录）
- 数据源：`[DEFAULT]` 单库（未启用 JUNIOR/SENIOR 双库）
- 脚本模式：只读，不写 Student / Enrollment

## 口径

对每个 `status != INACTIVE` 且未软删除的学生，比较两组数：

- **快照**：`Student.remainHours` / `Student.totalHours`（历史遗留字段）
- **台账**：该学生所有「有效报名」（`activeEnrollmentWhere`）的 `Enrollment.remainHours` / `totalHours` 之和

差额 = 快照 − 台账。容差 0.0001。差异类型：`REMAIN_ONLY` 仅剩余课时不一致 / `TOTAL_ONLY` 仅总课时不一致 / `BOTH` 两者都不一致。
